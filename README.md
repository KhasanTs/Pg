# RuVideoHub 14.1

Android-приложение для поиска видео с выбором одного активного источника.

## Встроенные источники

- RUTUBE
- VK Video — требуется ваш `access_token`
- MAIL.RU

OK, HDRezka, Filmix, Zona и Seena удалены из списка источников приложения.
Специальные скрейперы, обход защиты и хранение логинов/паролей для этих сайтов
в проект не входят.

## Умный поиск

Поиск работает только в выбранном источнике, но делает несколько вариантов
запроса и затем ранжирует найденные карточки на устройстве.

Учитываются:
- порядок слов;
- `ё`/`е`;
- пунктуация и лишние символы;
- русская/английская раскладка;
- недописанные слова и совпадение по началу слова;
- лёгкие опечатки;
- простая русская морфология (например, `смерть` и `смерти` считаются близкими).

Поэтому запрос вроде `смерть Стимпи` может высоко поставить результат
`Стимпи при смерти`, если источник вернул его среди кандидатов.

## Внешнее воспроизведение

Встроенный Media3/ExoPlayer удалён. Кнопка «Смотреть» передаёт найденный
видеопоток внешнему приложению через системный Android Intent.

## Браузерное расширение

В `browser-extension/Finish-Kiwi` находится расширение из предыдущей версии.
Оно работает отдельно от Android-приложения: через браузерные сетевые события
и страницу ищет видеопотоки HLS/DASH/прямые видео на сайтах с `<all_urls>`,
показывает найденные варианты и передаёт поток внешнему плееру.

Это именно вспомогательный браузерный инструмент, а не источник поиска внутри
RuVideoHub. Он не содержит логики обхода авторизации или защиты сайтов.

## Сборка

GitHub Actions настроен на:
- Java 17
- Gradle 8.7
- Android Gradle Plugin 8.6.1
- compileSdk 35
- minSdk 26

В текущем окружении Android SDK/Gradle не установлены, поэтому локальную
компиляцию здесь подтвердить нельзя. Для окончательной проверки используйте
GitHub Actions `Build APK`.
