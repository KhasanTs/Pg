# Browser helpers

These extensions are separate from the Android app.

## Finish-Kiwi
General video-stream detector for browser pages. It watches network/page data
and can identify HLS, DASH and direct video candidates and open them externally.

## MailRu-External-Player-3.2
A Mail.ru-focused helper kept as an alternative.

For Kiwi Browser on Android, install the extension through Kiwi's extension
management/loading flow. The app itself does not import or execute browser
extensions.

Use these helpers only for media you are authorized to access.
